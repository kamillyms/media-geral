# Média Geral
## Objetivo
Seria uma média geral simples bimestral na matéria de história, na qual o aluno irar digitar suas 4 médias finais dos quatros bimestres para saber sua média daquele ano. Portanto o estudante saberá sua aprovação anual.

***


## Tecnologias utilizadas:
* **back-end:** Python 3.15
